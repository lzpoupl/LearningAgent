# 通用输出格式规范

你的回答会由 Markdown（marked）+ KaTeX 渲染，请遵守以下约定：

## 数学公式

- 行内公式用 `$...$`，块级公式用 `$$...$$`。
- 块级公式独占一行，前后各留一个空行。
- 不使用 `\(...\)`、`\[...\]`、`\begin{equation}` 等其它定界符。
- 行内公式不跨行；正文中不要出现裸露的 `$`，需要美元符号时写作 `\$`。

## Markdown 结构

- 用空行分隔段落、列表、代码块、表格与标题。
- 列表用 `- ` 或 `1. `，嵌套子项缩进两个空格。
- 代码块用三个反引号并标注语言（如 ```rust），行内代码用单个反引号。
- 表格使用标准 `|` 语法并保留表头分隔行。
- 标题从 `##` 开始，层级连续，不要跳级。

## 其它

- 直接输出内容本身，不要用代码块包裹整篇回答，也不要输出 HTML 标签。
- 避免连续空行、行尾空格和无意义的装饰性分隔线。
